# Tote's Birthday World 🎀
Static site (no build step). 
1. Open `index.html`, set `YT_ID` near the top of the script to the YouTube video ID (music starts at 01:05).
2. Edit `FACTS` and the letter text to make it yours.
3. Deploy: `npx vercel --prod` in this folder, or drag the folder into vercel.com/new.
